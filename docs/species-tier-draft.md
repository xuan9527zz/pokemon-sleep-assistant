# 宝可梦物种梯级表

状态：已于 2026-09-20 接入网站评分、筛选、培养与去留判断；用户后续可继续逐只校订。

可执行唯一数据源：`skills/pokemon-sleep-scoring/scripts/species-tiers.js`。本文用于解释与人工复核，名单调整时必须同步修改脚本与测试。

## 1. 梯级定义

这张表回答“这个种族是否值得投入沙布雷继续严选”，不评价某一只个体的副技能、性格或食材路线。

- **S**：同定位中最强的种族，是主要严选目标。
- **A**：同岛屿存在更好的替代，或者当前对应食材需求不高，但它仍是该食材的最佳选择。
- **B**：堪堪可用，以已有优秀个体、过渡和临时补位为主。
- **C**：不进入严选考虑范围，不建议为其主动投入沙布雷。

C 级只表示“不严选”，不能触发自动放生。闪光、限定、收藏、已投入个体和特殊食材路线仍需人工处理。

## 2. 当前纳入范围

1. **树果手**：图鉴树果专长，以及实际占用树果位的树果骤增技能手。
2. **食材手**：图鉴食材专长。
3. **技能手**：纳入五只正式群体回复手，以及用户点名加入的咚咚鼠和海豹球（佳节）。
4. **特殊／幻之宝可梦**：单独定级，不与普通树果手、食材手或技能手混排。

其他技能手、壶壶、直接能量替代位以及单体／随机回复手暂不进入严选梯队。克雷色利亚、梦幻、达克莱伊和拉帝欧斯改在特殊／幻之宝可梦梯队中评价。

未进化个体继承所选最终形态的梯级。种族梯级与个体毕业判断必须分别展示。

## 5. 技能手梯队

当前技能手梯队评价五只正式群体回复手，并加入两只料理成功 S 严选目标。

| 梯级 | 宝可梦 |
|---|---|
| S | 沙奈朵、咚咚鼠 |
| A | 土台龟、巴布土拨、海豹球（佳节） |
| B | 仙子伊布、胖可丁 |
| C | — |

其他技能手目前不进入严选范围。以后由用户点名增加必须严选的技能岗位；正式比较时，群体回复与料理成功仍须在各自机制内部判断，不能直接拿触发次数互相比较。

## 6. 特殊／幻之宝可梦梯队

梦幻的梯级跟随当前选定的十项全能技能，不使用一个固定梯级。

| 梯级 | 宝可梦／技能形态 |
|---|---|
| S | 达克莱伊、克雷色利亚、拉帝亚斯、梦幻（树果骤增） |
| A | 水君、雷公、炎帝 |
| B | 梦幻（其他技能）、超梦、拉帝欧斯 |
| C | — |

特殊／幻之宝可梦的梯级同样只决定严选优先级。限定、特殊名额、梦幻技能选择、达克莱伊梦魇队伍条件和拉帝双龙组合仍需单独显示，不能压缩成一个普通技能手结论。

## 7. 严选应用口径

| 种族梯级 | 严选策略 | 个体判断 |
|---|---|---|
| S | 主要严选目标，可以持续投入沙布雷寻找毕业个体 | 仍须满足对应岗位的毕业面板与路线要求 |
| A | 次级严选目标；缺少 S 级替代或需要该食材时再投入 | 至少达到岗位最低线，资源充足时再追毕业 |
| B | 不主动长期严选，只使用现有的明显优秀个体或短期工具人 | 不能因为暂时可用就获得长期培养标签 |
| C | 不进入严选目标，不主动投入沙布雷 | 收藏与去留仍按安全规则人工判断 |

最终网站应显示“种族梯级＋个体质量＋毕业状态”，不再把种族表现和个体面板合成一个综合百分分。
